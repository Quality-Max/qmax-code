# qmax-code v1.40.2

This patch fixes Codex MCP configuration updates. Updating qmax's entry now
preserves other MCP servers and settings, including quoted table names and
table-like text inside multiline strings.

Invalid TOML and unsupported inline qmax definitions are rejected without
changing the file. Updates are atomic, use owner-only file permissions, and
preserve an existing config symlink.

Upgrade to v1.40.2 if you use Codex orchestration or the optional global Codex
MCP integration.
