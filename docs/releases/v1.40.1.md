# qmax-code v1.40.1

This security release rebuilds qmax-code with Go 1.27.3. That Go release makes
`crypto/x509` reject the compromised emSign root certificates described in
[GO-2026-6809](https://pkg.go.dev/vuln/GO-2026-6809), including on systems whose
root store has not yet removed them.

Users of earlier qmax-code binaries should upgrade to v1.40.1.
