# qmax-code v1.40.0

This release adds image descriptions for text-only CLI models, portable
handoff notes, and an explicit Haiku 5.5 option to the QA terminal that can
switch inference.

## Images for text-only CLI models

The Gemma 4 vision sidecar describes image attachments through Cerebras and
passes the description to your selected CLI model. It requires a Cerebras
API key. In the default `auto` mode, it runs only for known text-only
OpenCode models on the Z.AI coding plan. Use `always` for every CLI backend
or `off` to disable it:

```bash
qmax-code config set vision_sidecar auto
```

When the sidecar runs, image data is sent to Cerebras. The selected CLI
model continues to handle reasoning and tools. Failure and cancellation
paths preserve the existing attachment fallback behavior.

## Carry rejected approaches across backend switches

Record an approach and its supporting evidence before handing work to
another backend:

```text
/handoff reject Retry without backoff | Repeated requests hit the rate limit
/handoff
/handoff forget 1
```

These explicit notes survive backend switches, history compaction, and
session restarts. They are redacted and bounded to 12 KiB, with no extra
model call. Backend switches can remind you to record uncovered work;
notes are recorded only when you ask. The destination model is instructed
to respect them and explain any justified retry; compliance is not enforced.

Long-history handoffs also avoid repeatedly encoding entries that will be
dropped. See the [handoff guide](https://github.com/Quality-Max/qmax-code/blob/v1.40.0/docs/HANDOFF.md)
for details and the live evaluation procedure.

## Opt in to Haiku 5.5

Select Haiku 5.5 explicitly in `/orch`, or use:

```text
/model claude-haiku-5-5
```

It is available for Anthropic API and Claude Code workflows, with request
settings and cost estimates. The `haiku` shorthand and automatic chat
routing continue to use Haiku 4.5 until the upgrade is verified.

## Coverage and Go tooling

This release expands regression tests across commands, provider requests,
agent loops, authentication, sessions, setup, the terminal UI, and VNC.
CI now uploads coverage to Codecov.

The Go module path now matches the repository's capitalization:

```bash
go install github.com/Quality-Max/qmax-code@v1.40.0
```

## Install or update

```bash
curl -sL https://qualitymax.io/static/install-qmax-code.txt | bash
qmax-code --version
```

Download a single binary for macOS, Linux, or Windows on Intel or ARM.

third-party dependency licenses.
